# D2 Research Design and Path Rules

## Minimum Method Rule
- Use interview evidence (live interview, transcript, call notes, or prior interview record) plus at least one additional method, or record an explicit justified corpus-only exception.
- If interview evidence is absent and cannot be collected autonomously, add a `method_exception` note and route the limitation via `A51Ref`.

## Path Families
- `Product/User`
- `Process/Operations`
- `Technical/Platform`
- `Regulatory/Compliance`
- `Data/Analytics`

## Quality Gate
`research_quality_report.md` must include `Status: PASS` before D3 starts.
