# Support Ops Runbook — Triage SLA (Source 001)

Origin: ops team runbook, internally maintained by the support operations lead, last reviewed 2026-03-15.

## High-severity ticket SLA

High-severity tickets receive an initial agent response within 4 hours of arrival. The 4-hour window is measured from the ticket-creation timestamp in the ticketing system to the first agent claim or comment, whichever lands first.

## Critical-severity ticket SLA

Critical-severity tickets receive an initial response within 1 hour of arrival. (Out of scope for this contradiction example — included for context.)

## Escalation path

If the on-call agent is paged but does not acknowledge within 15 minutes, the page escalates to the team lead.
