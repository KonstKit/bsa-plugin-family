# D3 Opportunity/Response Modeling

## Output Contract
- `opportunity_or_response_map.md`
- `hypothesis_response_backlog.md`
- `prioritization_matrix.md`
- `prioritization_report.md` (`Status: PASS`)

## Prioritization Axes
- impact
- confidence
- effort
- reversibility
- dependency density
- strategic alignment

## Scoring Rule
- Use a normalized 1-5 desirability scale for every axis, where `5 = better`.
- Cost-like dimensions (`effort`, `dependency density`) must be converted into desirability scores rather than raw burden values.
- Every non-obvious score must have a one-line rationale or an `A51Ref`.
