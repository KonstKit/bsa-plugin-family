# Ops Runbook — Incident Response

Section 3.2 P0 incident handling

## Initial response window

P0 incident response begins within 15 minutes of page acknowledgement.
The on-call engineer triages, confirms scope, and pages the IM (incident
manager) within this window.

This window applies to business-hours and after-hours pages identically;
the after-hours rotation has 24/7 phone reachability so the 15-minute
target stays consistent.

Sign-off: Ops team lead, quarterly runbook review (last reviewed 2026-Q1).
